# zmk-config-forager

ZMK config for a PandaKB Forager (34-key, Seeed XIAO nRF52840 × 2).
Shield from [PandaKBLab/forager-zmk-module](https://github.com/PandaKBLab/forager-zmk-module),
a fork of [carrefinho/forager-zmk-module](https://github.com/carrefinho/forager-zmk-module).

GitHub Actions builds on every push. Flash **both halves from the same run**, every time.
